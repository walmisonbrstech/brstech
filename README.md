1. Módulo de Crédito & Captação
CCB (Cédula de Crédito Bancário): Mencione se o sistema calcula as parcelas usando a Tabela Price ou SAC, e se faz a emissão do documento da CCB.

CDB (Certificado de Depósito Bancário): Destaque como o sistema calcula a rentabilidade (ex: % do CDI pós-fixado) e se há provisão diária de juros.
